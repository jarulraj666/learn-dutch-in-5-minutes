## CEFR Level: A1 — Beginner | Skill: Speaking

The learner is a complete beginner. The goal is to build confidence in **producing** spoken Dutch — pronunciation, rhythm, and basic sentence construction.

### Language Complexity Constraints (A1)
- Maximum 8 words per dialogue line
- Present tense only (ik ben, jij bent, hij is)
- Use only the most common 500 Dutch words
- Introduce at most 8 new vocabulary items per episode
- Repeat each key phrase at least 3 times
- No subordinate clauses; short declarative and simple question sentences only
- Numbers: 1–20 only
- No idioms

### Skill Focus: Speaking

The viewer is **practising speaking Dutch aloud** alongside the video. The dialogue should:

- Use explicit "Spreek mij na:" (Repeat after me) prompts every 8–10 lines in the Core Dialogue phase so the viewer speaks along
- SpeakerA models correct pronunciation by saying a word or phrase slowly, then at normal speed
- Highlight tricky Dutch sounds: the Dutch G (guttural), IJ/EI, OE, UI — SpeakerA points these out briefly
- In the Recap phase, "Herhaal na mij:" drills are the main event: SpeakerA says the phrase slowly, SpeakerB echoes, then a beat of silence for the viewer to try
- Quiz questions test whether the viewer can **produce** the right phrase: "Hoe zeg je dit in het Nederlands?" or fill-in-the-gap spoken prompts
- Prefer `fill_gap` and `multiple_choice` quiz types

### Phase Breakdown

| Phase | Lines | Focus |
|-------|-------|-------|
| Introduction | ~15 | Greet the viewer, introduce the topic, explain they will be speaking along today |
| Core Dialogue | ~65 | Conversation with regular "Spreek mij na:" breaks; model pronunciation explicitly |
| Phrase Recap | ~46 | Intensive "Herhaal na mij:" drills — slow + normal speed for each phrase |
| Quiz | ~53 | 5-line announcement + 8 × 6-line rounds; questions ask viewer to recall and say phrases |

**Total target: ~179 dialogue lines**

### Dialogue Style
- SpeakerA is a patient pronunciation coach; SpeakerB is an enthusiastic student who models the speaking exercises
- After each "Spreek mij na:" prompt, SpeakerB demonstrates the response so the viewer has a model before trying
- Occasionally note Dutch-English false friends or surprising spellings (e.g. "ij" sounds like "eye")
- Start the introduction with a clear, slow pronunciation of the topic's key word
