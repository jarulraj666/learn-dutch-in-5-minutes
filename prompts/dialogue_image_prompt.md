# Dialogue Scene-Based Image Prompt Template

This file defines the image prompt structure for multi-scene dialogue video generation.

## Overview

For multi-image dialogue episodes, scene-specific image prompts are generated by:
1. Starting with the dialogue's base `image_prompt` (from Stage 1 LLM generation)
2. Appending scene-specific visual focus and description details
3. Passing the enhanced prompt to the image generation API

## Base Dialogue Image Prompt Template

The base prompt (stored in script["image_prompt"]) follows this structure:

```
3D stylized animation render of {scenario} - {title_hint}. 16:9 aspect ratio, Pixar aesthetic, warm lighting, highly detailed. Light, airy background colours — soft pastels, creamy whites, warm beiges, pale blues or light warm tones. Bright and cheerful feel. No dark or saturated backgrounds. Full background: the {scenario} environment fills 100% of the frame — rich, detailed, and in focus. Left 35-40%: {speaker1_gender} character ({speaker1_role}) positioned naturally, facing inward toward the center. Right 35-40%: {speaker2_gender} character ({speaker2_role}) positioned naturally, facing inward toward the center. Center 20%: open space — no characters, no obstructions.
```

## Scene Enhancement Template

For each detected scene (start_sec, end_sec, visual_focus, description), append:

```
Scene focus: {description}. Visual emphasis: {visual_focus}.
```

## Complete Example

**Input (base prompt from dialogue):**
```
3D stylized animation render of A coffee shop - Meeting a Friend. 16:9 aspect ratio, Pixar aesthetic, warm lighting, highly detailed. Light, airy background colours — soft pastels, creamy whites, warm beiges, pale blues or light warm tones. Bright and cheerful feel. No dark or saturated backgrounds. Full background: the coffee shop environment fills 100% of the frame — rich, detailed, and in focus. Left 35-40%: female character (Anna) positioned naturally, facing inward toward the center. Right 35-40%: male character (Marc) positioned naturally, facing inward toward the center. Center 20%: open space — no characters, no obstructions.
```

**Scene Details:**
- Scene 1: 0.0s-8.5s
  - Description: "Two friends greeting each other at the entrance"
  - Visual focus: "greeting and initial setup"

**Output (scene-specific prompt sent to image generator):**
```
3D stylized animation render of A coffee shop - Meeting a Friend. 16:9 aspect ratio, Pixar aesthetic, warm lighting, highly detailed. Light, airy background colours — soft pastels, creamy whites, warm beiges, pale blues or light warm tones. Bright and cheerful feel. No dark or saturated backgrounds. Full background: the coffee shop environment fills 100% of the frame — rich, detailed, and in focus. Left 35-40%: female character (Anna) positioned naturally, facing inward toward the center. Right 35-40%: male character (Marc) positioned naturally, facing inward toward the center. Center 20%: open space — no characters, no obstructions. Scene focus: Two friends greeting each other at the entrance. Visual emphasis: greeting and initial setup.
```

## Scene Detection

Scenes are identified via LLM analysis of dialogue timing:
- LLM receives dialogue lines with timestamps
- LLM outputs 5-6 distinct visual moments with boundaries
- Each scene maps to actual ASS subtitle segments (Stage 3a)
- Timing ensures image display aligns with dialogue

## Implementation Notes

- Base `image_prompt` comes from script["image_prompt"] (created during Stage 1)
- If base prompt missing, uses generic fallback template
- Scene descriptions and visual focus are LLM-generated
- Each scene prompt is independent but stylistically consistent
- Prompts are sent sequentially to image generation API

## Customization by Level

For different difficulty levels (A1A2, B1, B2), the base dialogue prompt can vary:
- A1A2: Simpler scenarios, fewer details
- B1: More complex scenes, richer descriptions
- B2: Advanced scenarios, nuanced visual focus

The scene enhancement template remains the same across all levels.
